Warung Sizzle — game masak cepat khas warung Indonesia. Ambil pesanan dari
papan pesanan, masak di dua kompor sebelum kesabaran pelanggan habis, pindah
ke piring, lalu sajikan ke tiket yang cocok. Empat menu (Nasi Goreng, Mie
Goreng, Sate Ayam, Es Teh Manis), sepuluh bahan, kombo untuk sajian cepat dan
tepat, masakan gosong dan salah saji memutus kombo. Satu shift 3 menit —
berapa piring yang bisa kamu sajikan?

## Cara main

```sh
node serve.ts
# buka http://localhost:8080
```

Klik bahan untuk mengisi wajan (atau tekan tombol 1–0), tunggu masakan
matang, klik wajan untuk memindahkannya ke piring, klik piring, lalu klik
tiket pesanan yang cocok. Sajikan selagi kesabaran masih tinggi untuk koin
maksimal. `?shot=start`, `?shot=play`, dan `?shot=end` membekukan state
deterministik untuk screenshot.
